# Dokumentasi My Finder

Selamat datang di pusat dokumentasi **My Finder** — aplikasi desktop Windows super ringan untuk mengelola daftar shortcut folder dan langsung membukanya di jendela File Explorer baru hanya dengan satu klik.

## Daftar Dokumentasi

1. **[Panduan Pengguna (Non-Teknis)](./panduan-pengguna.md)**
   Cocok untuk pengguna sehari-hari. Membahas cara menjalankan aplikasi, menambah & mengatur shortcut, pencarian cepat, drag & drop, pintasan keyboard, cara backup data, serta solusi kendala umum.

2. **[Panduan Pengembangan (Development Guide)](./panduan-pengembangan.md)**
   Cocok untuk mulai mengembangkan aplikasi. Membahas setup environment dari nol, cara menjalankan (`go run`, build debug, build rilis), alur kerja harian, debugging GDI/RAM/HiDPI, skrip verifikasi, serta troubleshooting umum.

3. **[Dokumentasi Teknis (Arsitektur & Developer)](./dokumentasi-teknis.md)**
   Cocok untuk memahami desain internal. Membahas arsitektur aplikasi, struktur modul Go, integrasi Win32 API & COM (`IFileOpenDialog`), mekanisme rendering GDI double-buffered, manajemen memori & HiDPI, format data `shortcuts.json`, dan panduan ekstensibilitas.
